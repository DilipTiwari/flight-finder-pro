# Roadmap

## Phase 1 — Free MVP launch

- Use mock/demo flight data
- Deploy on Vercel free tier
- Add privacy page and cookie consent
- Add affiliate link placeholders
- Track only consented analytics
- Validate traffic and route-search interest

## Phase 2 — Monetization tests

- Join affiliate/travel partner programs
- Replace placeholder affiliate URL
- Add affiliate disclosure text
- Track outbound clicks after consent
- Create SEO landing pages for popular routes

## Phase 3 — Live flight data

- Connect a live supplier API only after validation
- Add caching and rate limiting
- Keep API credentials server-side
- Add supplier error handling and fallbacks

## Phase 4 — Price alerts

- Add user email capture with explicit consent
- Save searches in a database
- Send alerts through a transactional email service
- Add unsubscribe flow
- Update GDPR/privacy policy

## Phase 5 — User accounts

- Add authentication
- Saved searches
- Alert preferences
- User dashboard
- Data export/delete request flow
